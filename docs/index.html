Biological age clocks, locally referenced

An open registry where laboratories publish the clock they use and the local reference they built for it. Entries hold model parameters and aggregate performance only. There is no patient data here, and there never will be.

Research use only. Nothing on this site is a medical device or clinical advice. Entries are submitted by laboratories and are self-reported unless marked verified. A local score describes a position among local peers; it does not predict mortality or measure the pace of aging.

    Calculator

    Computes biological age, the local standardized score and an approximate percentile using the parameters of the selected entry. Everything runs in your browser; nothing is sent anywhere.

    Groups come from the entry's empirical percentile cut points: P1 lowest 10%, P2 next 15%, P3 middle 50%, P4 next 15%, P5 highest 10%. The percentile is interpolated from those cut points, so it is approximate.

    Add your laboratory

    No account on this site and no server: you contribute through a pull request on GitHub.

    1. Fork the repository and copy registry/template.json to registry/clocks/<your-id>.json.
    2. Fill in your clock parameters, local recentering coefficients, cut points and aggregate performance.
    3. Run python scripts/build_registry.py --check. It rejects anything that looks like patient-level data.
    4. Open a pull request. A check runs automatically; maintainers review it. New entries are shown as self-reported.

    Only aggregates and model parameters are accepted: no identifiers, no per-patient values, no per-patient scores.

    About

    The reference model, pheno_max_v2, is a six-marker PhenoAge-derived model fitted with the BioAge R toolkit (Kwon & Belsky, GeroScience 2021) on NHANES III, evaluated on NHANES IV, and recentered locally for age and sex. The survival parameters come from NHANES; the local step defines a reference and does not recalibrate mortality risk. The full pipeline, without data, is in this repository.

    The entry marked example is synthetic and exists only to demonstrate the interface.
